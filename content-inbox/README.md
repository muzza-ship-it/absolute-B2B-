# Content Inbox

Archive of raw material recovered content was transcribed from — kept for
traceability alongside the code, per docs/CONTENT_INGESTION.md.

- `screenshots/` — screenshots or frame captures from a screen recording of
  the live/prior Absolute B2B site.
- `raw-text/` — any exported text/JSON/CSV content supplied directly.

Nothing here is rendered by the application. When a person uploads a file
or image directly in chat, Claude reads it from the chat upload location
and transcribes relevant content into the appropriate `frontend/src/data/`
file — a copy is archived here afterward as a record of provenance, not as
the working source of truth (the data files are the working source of
truth for what renders on the site).
